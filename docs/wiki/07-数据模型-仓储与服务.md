## 2. ORM 模型 — `app/models/`

统一基类 [base.py](file:///d:/PythonProjects/personal_rag/backend/app/models/base.py)：`Base`（含 `naming_convention`）+ `TimestampMixin`（`created_at/updated_at`）。

| 模型 | 表 | 关键字段 |
| --- | --- | --- |
| `Tenant` | `tenants` | `tenant_key`（唯一）、`name` |
| `ChatSession` | `sessions` | `id`（uuid4 hex，前端 session_id 同形）、`tenant_id`、`last_active_at` |
| `Message` | `messages` | `session_id`、`role`、`content`、`seq`（会话内单调）、`tool_context` |
| `Document` | `documents` | `document_key`、`version`、`is_current`、`source`、`file_hash`、`tenant_id`、`status`、`meta`(JSONB) |
| `IngestTask` | `ingest_tasks` | `id`(uuid hex)、`document_id`、`tenant_id`、`status`、`progress`、`error` |
| `AnalyticsTable` | `analytics_tables` | `table_name`、`display_name`、`description`、`tenant_id`、`is_enabled` |
| `AnalyticsColumn` | `analytics_columns` | `table_id`、`ordinal`、`column_name`、`data_type`、`description`、`enum_values`(JSONB)、`is_primary` |
| `SqlAudit` | `sql_audit` | `actor`、`tenant_id`、`sql`、`ok`、`row_count`、`elapsed_ms`、`redacted_columns`、`error` |
| `LlmUsage` | `llm_usage` | `scene`、`model`、`actor`、`tenant_id`、`session_id`、prompt/completion/total tokens、`elapsed_ms` |

**Document 版本约束**（[document.py](file:///d:/PythonProjects/personal_rag/backend/app/models/document.py)）：
- `UniqueConstraint("document_key","version")` 唯一版本；
- `document_key IS NULL` 标识未版本化历史记录（向后兼容）；
- 部分唯一索引 `uq_documents_current_key`（`document_key` UNIQUE WHERE `is_current`）保证每文档族只有一个当前版本；
- CheckConstraint 保证 `is_current=True` 时必为 `ready`。

**Message.tool_context**：独立列存本论 Agent 工具轨迹（执行过的 SQL + 结果行），只喂模型不污染前端渲染（多轮追问必需）。

**AnalyticsTable/AnalyticsColumn 安全语义**：不存业务数据，只存结构描述与少量枚举值；`is_enabled=False` 即从 prompt 消失；`tenant_id IS NULL` 表示共享表；若某列枚举值敏感应清空。

## 3. 仓储 — `app/repositories/`

| 仓储 | 职责 |
| --- | --- |
| `BaseRepository` | 持有 AsyncSession，只 flush 不 commit，事务边界交由 service |
| `DocumentRepository` | `get_by_hash/get_by_id/list_by_tenant/upsert/delete`（跨租户视为不存在） |
| `DocumentVersionRepository` | `lock/reserve/owned/history/publish` + `document_key/original_name` 工具 |
| `SessionRepository` | `create/exists/get_recent_messages/next_seq/add_message/touch/lock_session/delete` |
| `IngestTaskRepository` | `create/get/update_status` |

`SessionRepository.lock_session` 用 `pg_advisory_xact_lock` 保证同一 session 并发追加算出唯一 seq，避免撞 `uq_messages_session_id_seq`。

## 4. 服务 — `app/services/`

### SessionService — [session_service.py](file:///d:/PythonProjects/personal_rag/backend/app/services/session_service.py)

PG 是事实来源，Redis 是热缓存：

| 方法 | 行为 |
| --- | --- |
| `create(tenant_id)` | uuid4 hex，写 PG，回 session_id |
| `exists(session_id, tenant_id)` | 带租户 ACL |
| `get_history(session_id, tenant_id)` | 命中缓存返回，miss 从 PG 回源并 `reheat`；带出 `tool_context` |
| `append(session_id, tenant_id, msg)` | 事务内 `lock_session→next_seq→add_message→touch`，再 `cache.append`（LTRIM+EXPIRE） |
| `delete(session_id, tenant_id)` | 删 PG + 缓存 |

`max_history`（默认 20）、`ttl`（默认 3600s）对齐 `settings.max_history_messages/session_ttl_seconds`。

### IngestionService — [ingestion_service.py](file:///d:/PythonProjects/personal_rag/backend/app/services/ingestion_service.py)

| 方法 | 行为 |
| --- | --- |
| `queue_ready()` | ARQ 池是否就绪 |
| `submit(file_path, ...)` | 建档（legacy upsert 或 version `reserve`）+ 入队，立即返回 task_id |
| `get_status(task_id, tenant_id)` | 读 PG 真相；跨租户 404 |
| `version_history/activate_version` | 版本历史/激活（回滚） |
| `delete_document` | 清向量→删副本→删行，fail 可重试 |

## 5. 数据库层 — [database.py](file:///d:/PythonProjects/personal_rag/backend/app/database.py)

`Database`（单例 `db`）：`create_async_engine`（asyncpg）+ `async_sessionmaker(expire_on_commit=False, autoflush=False)`；`init/dispose/healthcheck/create_all`。`create_all` 仅供开发/测试，生产用 Alembic。

## 6. Redis — [redis.py](file:///d:/PythonProjects/personal_rag/backend/app/cache/redis.py)

`RedisClient`（单例 `redis_client`）：惰性异步连接；`SessionCache` 用 Redis List（`session:{id}:history`）做会话热缓存。Redis 只是缓存/队列承载，丢失可从 PG 重建。

## 7. 会话与消息的并发与一致性

- 历史事实来源是 `messages` 表（`seq` 单调排序）。
- Redis `LTRIM -max_history -1` 保留最近 N 条，`EXPIRE ttl`。
- 追加在事务内持有 advisory lock，避免并发算出重复 seq。
