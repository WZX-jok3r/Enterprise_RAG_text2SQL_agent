# 02 · 关键类与函数

> 按包组织，列出核心类/函数的职责与位置。路径均为 `backend/app/...`，点击可跳转源码。

## 1. 入口与中间件 — `app/main.py`

| 符号 | 职责 |
| --- | --- |
| `create_app()` | 应用工厂：注册中间件、挂载 `/api` 路由、注册异常处理器、可选 `/metrics` |
| `lifespan()` | 启动/关闭外部资源：`db.init()`、`redis_client.init()`、ARQ 连接池、验证安全配置 |
| `HttpMetricsMiddleware` | 纯 ASGI 中间件，统计请求数与耗时（路径归一化防标签基数爆炸） |
| `_normalize_path()` | `/documents/123/status` → `/documents/{id}/status` |
| `PerformanceMiddleware` | 可选请求级数值采集（默认关闭） |
| `TraceIdMiddleware` | 生成/透传 `X-Request-ID`，贯穿 HTTP→Agent→SQL→worker |

## 2. 配置 — `app/core/config.py`

`Settings(BaseSettings)` 全局配置单例 `settings`（`get_settings()` 带 `lru_cache`）。

关键字段与方法：

| 成员 | 说明 |
| --- | --- |
| `siliconflow_api_key` / `llm_model` / `embedding_model` / `rerank_model` | 模型与凭据 |
| `vector_dim` / `qdrant_collection_name` / `retrieval_mode` / `prefetch_k` | 向量库与检索 |
| `top_k` / `rerank_candidates` / `score_rel_ratio` / `score_abs_min` / `score_confident` / `score_min_keep` / `score_drop_all_below` | 召回与低相关过滤 |
| `rag_tenant_keys` / `default_role` / `rag_tenant_roles` / `sql_redact_columns` | 鉴权与 RBAC |
| `sql_max_rows` / `sql_timeout_ms` / `sql_inline_max_rows` / `sql_max_retry` / `analytics_sync_on_ingest` | SQL 护栏 |
| `analytics_db` / `analytics_ro_user` / `analytics_employee_user` / 对应密码 | 双只读/受限账号 |
| 属性 `tenant_keys` | 解析 `RAG_TENANT_KEYS` → `{api_key: tenant_id}` |
| 属性 `auth_enabled` | 是否启用鉴权（`tenant_keys` 非空） |
| 属性 `tenant_roles` / `redact_column_set` / `role_for` | 角色与脱敏列解析 |
| 属性 `postgres_url` / `sync_postgres_url` / `analytics_url` / `sync_analytics_ro_url` / `sync_analytics_url` | 各类连接串（async/同步、只读/写） |
| 属性 `effective_ro_password` / `effective_employee_password` | 只读/受限角色实际口令（非 development 强制显式配置） |
| `validate_security()` | 生产口径安全校验（非 development 必须开鉴权、employee 默认角色、显式口令等） |
| 属性 `supported_extensions` | `.pdf/.docx/.xlsx/.md/.txt` |

## 3. 安全与租户 — `app/core/security.py`

| 符号 | 职责 |
| --- | --- |
| `Principal` (dataclass) | 已解析身份：`tenant_id`、`authenticated`、`role`、`scopes`；属性 `can_see_sensitive`、`can_run_sql`、方法 `redact_columns()` |
| `apply_tenant_acl(client_filter, tenant_id)` | **唯一**租户过滤构造入口：丢弃客户端/模型传的租户键，强制注入认证租户 |
| `resolve_principal(x_api_key, authorization)` | 解析请求头→Principal：鉴权关闭→匿名；缺 Key→401；无效→403；未知角色→显式失败 |
| `ROLE_ANALYST` / `ROLE_EMPLOYEE` / `KNOWN_ROLES` / `PRIVILEGED_ROLES` | 角色常量池 |

## 4. Agent 编排 — `app/agent/`

### `loop.py`

| 符号 | 职责 |
| --- | --- |
| `MAX_STEPS=5` / `WALL_CLOCK_SECONDS=60` / `MAX_LLM_CALLS=8` / `MAX_TRACE_ROWS=5` | 上界常量（前三个构成五重防护中的三重） |
| `AgentState` (dataclass) | 每请求独立状态：`question/history/steps/llm_calls/tool_calls/seen_calls/final_answer/degraded/route`、RBAC 的 `redact/actor`、多轮工具轨迹 `executed_sql/sql_result_rows/...` |
| `AgentLoop` | 有界状态机本体，`run()` 为主入口（逐事件 yield，可直接转 SSE） |
| `AgentLoop.run()` | 关卡一规则路由 → 强路由（SQL/RAG）或关卡二 LLM 循环 → `_finalize` |
| `_run_forced_sql()` | 规则命中 SQL：`list_data_tables` + `_exec_sql_via_engine` |
| `_run_forced_rag()` | 规则命中 RAG：直接 `kb_search` |
| `_run_llm_loop()` | LLM 工具选择循环，含墙钟/LLM 调用/步数/重复调用检测 |
| `build_messages()` | 组装 system + 历史（含工具轨迹）+ 本轮问题 |
| `build_tool_context()` | 把本轮 SQL + 结果行渲染成下轮可读文本（多轮追问） |
| `_exec_tool()` / `_exec_sql_via_engine()` | 工具执行包装；`kb_search` 执行后补发 meta 帧 |
| `_finalize()` | 生成最终答案，先补 meta 再 delta+done，写指标，回传 tool_context |
| `_compose_answer()` | 用模型把工具观察组织成答案（澄清优先，成本上界兜底） |
| `_record_metrics()` | 写 `route`/`degraded`/`steps`/`tool_calls` 指标 |
| `get_agent_loop()` | 进程级单例 |

### `router.py`

| 符号 | 职责 |
| --- | --- |
| `Route` (enum) | `RAG` / `SQL` / `LLM_DECIDE` |
| `RouteDecision` (dataclass) | 路由结果 + 命中信号（`matched_aggregation/column/doc_word`）可审计可断言 |
| `route_by_rules(question, ...)` | 纯函数规则路由，四步判定：文档意图优先→聚合+列名强路由 SQL→仅列名交 LLM→无信号交 LLM |
| `AGGREGATION_WORDS` / `DOC_WORDS` / `DEFAULT_COLUMN_WORDS` | 词表 |
| `build_column_words(schemas)` | 从 schema 元数据动态构造列语义词 |

### `agent/tools.py`

| 符号 | 职责 |
| --- | --- |
| `ToolOutcome` (dataclass) | 工具结果统一结构：`ok/name/observation/summary/payload` |
| `describe_exception()` | 遍历异常链找根因（规避 504 被包装异常掩盖） |
| `AgentTools` | 工具执行器，可注入假实现供单测 |
| `AgentTools.kb_search()` | 复用 `Retriever.search`，强制 `apply_tenant_acl` 注入租户 |
| `AgentTools.sql_query()` | `guard_and_record` + `executor.execute`，只执行模型写好的 SQL |
| `AgentTools.sql_answer()` | 走 Text2SQL 引擎回答自然语言统计问题（session 生命周期收在此处） |
| `AgentTools.list_data_tables()` | 读 schema 元数据 + 敏感列过滤 + 渲染 |
| `AgentTools.dispatch()` | 统一分发（**必须传 tenant_id**） |

### `events.py`

SSE 事件契约。既有 4 类（字段冻结）：`ev_meta` / `ev_delta` / `ev_done` / `ev_error`；新增 6 类：`ev_route` / `ev_tool_call` / `ev_tool_result` / `ev_sql` / `ev_clarify` / `ev_degraded`。

## 6. 向量检索 — `app/vector/`

| 符号 | 职责 |
| --- | --- |
| `VectorStore` | Qdrant 封装：集合管理、写入、检索、按 metadata 删除、rerank、低相关过滤 |

| `EmbeddingClient` | 调 `/embeddings`，`embed()` / `embed_single()`，带重试 |
| `RerankClient` | 调 `/rerank`，`rerank()`，带重试 |
| `current_revision_ids()` | 从 PG 读当前发布版本 id（`@lru_cache`，失败 fail-closed） |
