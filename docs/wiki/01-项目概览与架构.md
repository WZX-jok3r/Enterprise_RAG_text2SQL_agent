# 01 · 项目概览与架构

## 1. 定位与价值

这是一个**可演示、可测试的企业知识库问答 Agent 工程实践项目**，定位为受控内部试点，尚未完成生产质量与容量验收。

它解决的核心问题是：**“相关片段 ≠ 完整数据”**——纯 RAG 把上万行表格切成片段后，即使召回片段高度相关，也无法证明覆盖了全部满足条件的记录。因此把「检索相关证据」与「全量精确计算」分配给不同工具：

- 政策、合同、规格、操作流程 → **RAG 检索 + 引用**
- 人数、金额、排名等全量统计 → **只读 SQL 计算**
- 需同时获取制度依据与统计结果 → **Agent 组合调用**

历史回归案例：部门人数对比，纯 RAG 算出差值 1017（错），Text2SQL 用 `GROUP BY department` 得到数据库真值 32（对）。

## 2. 技术栈

| 层 | 技术 | 用途 |
| --- | --- | --- |
| 前端 | Vue 3 + TypeScript + Pinia + Vite | SPA、SSE 流式渲染、执行轨迹可视化 |
| Web | FastAPI + uvicorn | REST + SSE 接口 |
| 编排 | 手写有界状态机（无框架） | Agent 工具循环 |
| 向量库 | Qdrant | Dense + BM25 稀疏向量、混合检索 + RRF |
| 业务库 | PostgreSQL（kb_analytics） | Text2SQL 只读查询 |
| 元数据库 | PostgreSQL（rag） | 会话/文档/任务/审计/用量 |
| 缓存/队列 | Redis + ARQ | 会话热缓存 + 异步入库队列 |
| ORM/迁移 | SQLAlchemy 2.0 (async) + Alembic | 持久化与迁移 |
| SQL 安全 | sqlglot | AST 白名单校验 + LIMIT 注入 |
| 模型网关 | SiliconFlow（OpenAI 兼容） | LLM / Embedding / Rerank |

默认模型：DeepSeek-V3.2（LLM）、BGE-M3（Embedding）、BGE Reranker（Rerank）。检索口径：Dense + BM25 双通道、RRF 融合、交叉编码器重排、分数量纲过滤。

## 3. 核心设计亮点

1. **混合检索**：Dense 语义 + BM25 词面（型号/专有名词）+ RRF 融合 + 交叉编码器重排。仅对 rerank 分数用绝对阈值，避免误删。
2. **Text2SQL**：生成/校验/执行分离，schema linking + few-shot + 错误反馈重写，只读执行。
3. **SQL 多层安全**：sqlglot AST 白名单 → 只读事务+超时+行上限 → 独立只读账号列级授权 → RLS 租户隔离，四层纵深防御。
4. **多租户收敛**：检索侧 `apply_tenant_acl` 单一入口；SQL 侧 `is_shared`/`tenant_id` 双维度 + fail-closed RLS。
5. **有界 Agent 状态机**：步数/墙钟/LLM 调用/重复调用/失败降级五重防护，详见 `agent/loop.py` 文件头。
6. **版本化入库**：同名版本链、完整写入后发布、历史隐藏、回滚与删除。
7. **SSE 执行轨迹**：答案 + 路由 + 工具调用 + SQL + 澄清 + 降级事件，便于问题定位。

## 4. 两大请求链路

### 4.1 在线问答链路

1. 服务端解析 `X-API-Key` 或 `Authorization: Bearer`，得到 `Principal`（租户 + 角色）。
2. 文档问题 → RAG；明确统计问题由规则前置路由到 SQL；其他交 LLM 选工具。
3. 检索与 SQL 各自执行权限约束，模型无法通过工具参数指定另一租户。
4. 工具返回文档证据或查询结果，Agent 生成答案；SQL 截断/澄清/降级状态反馈给用户。
5. SSE 推送来源、工具轨迹、答案；会话及有限工具上下文持久化供追问。

### 4.2 文档入库链路

1. `POST /documents` 保存不可变版本文件，登记 Document(pending) + IngestTask(queued)，入队 ARQ。
2. worker 执行解析、分块、Embedding、向量写入。
3. 新版本完整写入成功后发布；未完成/失败版本不替代当前版本。
4. 检索读版本登记，只允许当前已发布版本参与召回；可回滚旧版本。

**当前边界**：API 上传的表格只进 RAG，尚不支持同步发布/回滚 SQL 数据表（版本化入库 `analytics_sync` 恒为 `attempted:false`）。
