# 08 · 前端架构

## 1. 技术栈与目录

Vue 3 + TypeScript + Pinia + Vite；依赖 `vue`、`pinia`、`markdown-it`。构建 `npm run build`（`vue-tsc --noEmit && vite build`）。

```text
frontend/src/
├── main.ts            # createApp + Pinia
├── App.vue            # 顶部栏 + 租户 Key 设置 + ChatView + UploadPanel
├── api/
│   ├── client.ts      # fetch/SSE 客户端
│   └── types.ts       # 与后端 Pydantic 对应的 TS 类型
├── stores/
│   └── chat.ts        # Pinia 会话状态（legacy/agent 双模式）
├── components/
│   ├── ChatView.vue
│   ├── MessageBubble.vue
│   ├── SourcesList.vue
│   ├── UploadPanel.vue
│   └── AgentTrace.vue # 执行轨迹可视化
└── styles/main.css
```

## 2. API 客户端 — [client.ts](file:///d:/PythonProjects/personal_rag/frontend/src/api/client.ts)

| 函数 | 说明 |
| --- | --- |
| `getApiKey/setApiKey/clearApiKey` | API Key 仅在运行时存 `localStorage`（不烘入构建产物） |
| `request<T>()` | 通用 fetch，自动带 `X-API-Key`，统一解析 `{error:{message,code,status}}` |
| `chat()` / `chatStream()` | 多轮（非流式/SSE）走 `/chat`、`/chat/stream` |
| `agentStream()` | Agent SSE 走 `/agent/stream`（额外收 6 类轨迹事件） |
| `agentRoute()` | 规则路由调试 |
| `createSession/deleteSession` | 会话管理 |
| `uploadDocument/getIngestStatus/listDocuments/activateDocumentVersion/deleteDocument` | 文档上传与版本 |
| `verifyApiKey()` | 用一次列文档探测 Key 合法性 |
| `consumeSse()` | 共用 SSE 解帧：按 `\n\n` 切帧、`TextDecoder(stream:true)` 处理中文 UTF-8 |

## 3. 状态管理 — [chat.ts](file:///d:/PythonProjects/personal_rag/frontend/src/stores/chat.ts)

Pinia store `useChatStore`：

| 状态 | 说明 |
| --- | --- |
| `sessionId` / `messages` / `status` / `error` / `topK` | 会话与渲染 |
| `mode: "legacy" | "agent"` | 通道切换（agent 模式有执行轨迹） |
| `ChatMessage.channel` | `rag`/`sql`/`multi` 打标 |
| `ChatMessage.trace` / `stats` / `clarify` | Agent 轨迹 / 统计 / 澄清 |

关键 action：

- `ensureSession()`：仅当本地 session 与当前租户指纹（`keyFingerprint()` 的 djb2）一致才复用，否则新建，防跨租户串会话。
- `sendMessageStream()` / `sendMessageAgent()`：SSE 逐段增量渲染；Agent 模式把事件累积成 `trace`。
- 事件处理原则：**未知 type 一律静默忽略**（与后端“扩帧不改帧”配套，旧前端不崩）。
- `stopStream()` / `resetSession()`：AbortController 中断 + 清会话重建。

## 5. SSE 事件类型 — [types.ts](file:///d:/PythonProjects/personal_rag/frontend/src/api/types.ts)

`StreamEvent` 联合类型：既有 4 类 `meta/delta/done/error`（字段冻结）+ 新增 6 类 `route/tool_call/tool_result/sql/clarify/degraded`。`done` 可带 `agent_stats`（steps/llm_calls/tool_calls/degraded_reason/elapsed_ms）。

## 6. 前端 nginx

`frontend/nginx.conf` 关闭 SSE 缓冲/缓存；默认仅代理 `/api/v1/`（`/metrics` 不对外）。
